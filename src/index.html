Step 1 — Download Wine

        
This project uses Wine 11.11. Download & Install sets up the pinned build.

        

          Wine 11.11 is pinned for this project.
        

        

          

            
Downloading…

            
          

          

        

        

        

          🔑
          Installation will ask for your Mac login password (not your Apple ID) to remove the "App is damaged and can't be opened" message from Wine. This will be fixed in a future release.
        

        

          
          
          
          
        

      


      
      

        
Step 2 — Create Bottle & Install Steam

        

          Choose where to create your Wine bottle, then the app will initialise it and
          download SteamSetup.exe and run it inside the bottle.
        

        

          If no bottle location is given, the bottle will be created at
          ~/Library/Application Support/TruckersMP-Launcher/TruckersmpBottle
          

          ⏳ Please wait for Steam setup to fully finish before proceeding to the next step.

Step 3 — Install DXMT

        

          Download the latest DXMT release from
          github.com/3Shain/dxmt — grab the
          .tar.gz file. Then drop it below or browse to it.
          The app will extract it and wire it up automatically.
        

        

          
          

        

        
— or install from file manually —

        

          
          

            
            
          

        

        

        

          
          
          
        

      


      
      

        
Setup Complete!

        

          Standalone Wine and your bottle are ready.
        

        

          Install ETS2: Open Steam inside the bottle and install
          Euro Truck Simulator 2 through it. The launcher will detect
          the game directory automatically when you launch.
